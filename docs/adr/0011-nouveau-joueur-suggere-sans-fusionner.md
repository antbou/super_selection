# Nom inconnu : on suggère des noms proches, on ne fusionne jamais

Taper `Pizza` alors que le carnet contient `[IMP] Pizza` crée un second joueur (ADR 0002). Pour limiter les fautes de frappe, la fiche d'un joueur inconnu partout affiche « Nouveau joueur » et les noms qui contiennent le nom tapé (ou l'inverse). Le joueur est quand même enregistré ; la correction se fait à la main : `delete <nom tapé>` (confirmation demandée), puis taper le bon nom ; `edit <nom>` (ADR 0016, qui a absorbé `rename`) sert à corriger un joueur déjà ancien et refuse un nom déjà pris. Le renommage refuse un nom déjà pris : jamais de fusion automatique.
