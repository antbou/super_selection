# Pas de mode 2v2 spécial

La fiche d'un joueur affiche toujours ses deux rangs, en 1v1 et en 2v2. En 2v2, le classement est individuel (les deux coéquipiers ont les mêmes points). Il n'y a ni notion d'équipe, ni saisie de deux noms, ni mode à choisir : en 2v2, on tape les noms un par un. Le but est de rester simple : taper un nom, voir le rang, noter un style.
