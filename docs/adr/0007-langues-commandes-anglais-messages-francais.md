# Commandes en anglais, messages et code en français

Les commandes sont en anglais (`show`, `list`, `help`, `update`…) parce que les joueurs les connaissent déjà et qu'elles sont courtes. Tout le reste est en français : les messages, la doc et les noms dans le code (`Carnet`, `croiser`). Les mots-clés de style sont aussi en anglais (`aggressive`, `defence`), comme dans le jeu, et leurs variantes françaises sont reconnues.
